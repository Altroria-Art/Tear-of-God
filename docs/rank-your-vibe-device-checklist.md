# Rank Your Vibe — physical phone acceptance checklist

Use a test account and a non-production environment. Record device, OS, browser, date, and any failed step. This checklist is **pending human testing**; Chrome mobile emulation is not a substitute.

Run on iPhone/Safari and Android/Chrome when available:

- [ ] Open Home at portrait width. Hero, feed cards, sticky tabs, bottom navigation, and safe-area spacing stay visible without horizontal scrolling.
- [ ] Rotate to landscape and back. Controls and open dialogs remain usable; no content is clipped.
- [ ] On Create, Quick Add three items. Tap an item to assign a tier; long-press/drag an item between tiers and back to Unranked. The page scrolls normally when swiping outside cards.
- [ ] Open tier settings and the item picker. Close with the close button and by tapping outside. Focus returns to the triggering control when using a hardware keyboard.
- [ ] Open the on-screen keyboard for login, Quick Add, title, hashtags, and comments. The active field and submit action remain reachable; keyboard dismissal does not leave a blank gap.
- [ ] Publish a test ranking once, then try a rapid double tap. Confirm one post, correct tiers/items, and the same detail after refresh.
- [ ] Upload a photo from the gallery and, if offered, the camera. Check preview, progress, failure message, and retry on a deliberately invalid file.
- [ ] Like, bookmark, follow, comment, open Share and download/export on a test post. Return with browser Back and confirm state persists.
- [ ] Switch Thai/English and Light/Dark. Check long Thai labels, focus rings, contrast, and bottom navigation in both themes.

Record screenshots or a short screen recording for any failure, with the step number and expected versus actual result. Do not mark a step passed until it has been performed on the physical device.
